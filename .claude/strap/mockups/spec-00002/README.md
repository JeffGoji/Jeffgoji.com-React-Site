# jeffgoji.com V2 Mockups — Spec 00002

Dark motorsport-editorial redesign. Self-contained HTML/CSS/vanilla-JS mockups that serve as the **visual + structural contract** (Tier-1) for the React port.

## How to open

Double-click **`index.html`** in a browser (Chrome/Edge/Firefox). No build step, no server — everything runs from `file://`. Fonts load from Google Fonts (internet); all imagery is generated offline as SVG placeholders, so the layout renders with or without a connection.

To see responsive / mobile behavior: open any page, resize below **768px** (or use DevTools device toolbar) — the navbar collapses to a toggle menu. Breakpoints: 360 / 768 / 1024 / 1440.

## Port notes (mockup-as-contract)

- `assets/tokens.css` maps 1:1 into `src/scss/styles.scss` Sass vars + Bootstrap `$theme-colors`. **Declare the map BEFORE `@import "bootstrap/scss/bootstrap"`** — the current order (styles.scss:2) makes the override ineffective.
- Placeholder `<img>`s (generated by `ph()` in app.js) stand in for production **webp with `srcset`/`sizes` + `loading="lazy"`**.
- The mini-markdown renderer mirrors the production `react-markdown` + `remark-gfm` `p`/`img`/`a` behavior — production keeps `react-markdown` (no `dangerouslySetInnerHTML`).
- Data shapes in `mock-data.js` match `Cars.json`, `{na,Msm,nd,c8}Blog.json`, and the `build-gallery.mjs` manifest item shape (`{original, thumbnail, originalAlt, thumbnailAlt}`).
