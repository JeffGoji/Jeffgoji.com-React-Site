Design system · v2.0

The contract

Dark motorsport-editorial, tuned for reading comfort — a softer charcoal canvas, warm off-white text, premium racing red, industrial type. Every token below is defined in assets/tokens.css as a CSS custom property and ports 1:1 into the production SCSS + Bootstrap $theme-colors map.

Logo — "The Goji Line"

Replaces src/assets/images/logo.gif with an inline SVG. The mark is a racing line sweeping through a corner apex, bent into a "G", with a white apex dot. Scales crisp at any size; recolours via currentColor/token.

assets/logo.svg is the deliverable file.

Palette — softer charcoal + premium red

Refined from the harsh #ff0000; off-brand blues dropped entirely. Softer Dark revision: the canvas is lifted off pure black to a true charcoal (#141418) and body text softened to a warm off-white (#D8D4CD, ~12:1) so long reading surfaces don't strain. Headings stay brighter; the black+red identity is preserved.

Typography

Archivo (display / headings) · Inter (body) · Space Mono (telemetry / data chips). Self-host in production; Google Fonts links here.
